01 / WAFER

看得懂整片晶圓的資料

在華邦電子 {y} 年多，我負責晶圓廠內部的工程資料系統。熟悉 Wafer、Shot、Die、Defect 每一層的製造資料，能和良率、缺陷工程師用同一種語言溝通。

02 / SHOT

先找問題，再設計解法

使用者常會直接描述心中的畫面，但那往往只是解法之一。我習慣先傾聽，再往下追問背後的目的，找出真正要解決的問題，再以此設計最適合的介面。

03 / DIE

從介面到資料庫一手包辦

Angular 前端、C# 後端、Oracle SQL / PL/SQL 與 ETL 排程。設計時同時考慮資料表、效能、資料保存與 API 架構，讓系統不只能用，還能長期穩定運作。

04 / DEFECT

把 AI 真正用進工作

持續自學 AI，並導入團隊流程，協助建立專屬的 AI Skills，提升開發、除錯與文件撰寫效率。你現在看的這個網站，也是我和 AI 助理一起打造的。
