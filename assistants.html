我的 AI 小助理們

每個小助理都有自己的名字、個性和專長，各自負責生活與工作中的不同事情。

團隊架構

目前是架構階段：先只啟用幕僚長，其他助理的提示詞先備妥，需要時再啟用。

運作守則

  • 一件事一個地方：同一份結果的微調回在 thread，換成別的工作就開新 thread 或交給專職助理。
  • 派工只傳路徑：長資料放進 /workspace，對話裡只傳檔案路徑。bot 之間的訊息也會算用量。
  • 長期規則存進記憶：說一次並請它記住。共用記憶只有姓名、時區等少數事實，團隊共同規則要放在 /workspace 的檔案裡。
  • 少叫醒：流程穩定後才開 Routine，頻率寫死。每次執行都花用量，測試也是。
  • 安全靠規則，不靠分工：所有 bot 共用同一台電腦、登入狀態和憑證，只請 bot 記住界線也不夠，要搭配核准和 Ask first 規則。

啟用節奏

尚未開始，等有核心專案時再照這個節奏進行。

  1. 第 1 週：挑一個核心專案，先由 Iris 親手做，產出滿意了再拆給專職助理。
  2. 第 2 週：只觀察，不新增 bot。
  3. 第 3 週：補上真正缺的角色，停用沒用到的。
  4. 第 4 週：流程穩定了，才開始設定排程。

如何培養新的小助理

  1. 在 Grok Bot 建立新的 bot，設定名字、外型和顏色。幕僚長要用 Create primary Bot 或 Choose an existing Bot 指定為主要 bot。
  2. 在上方卡片按下「複製提示詞」，貼成這隻 bot 的第一則訊息。個人 bot 沒有描述欄位，工作和規則都在對話裡交代。
  3. 連接需要的 App，並設定「對外寄信前先問我」的 Ask first 規則。已連接的 App 每隻 bot 都能用，要真的用到才連。
  4. 啟用專職助理後，告訴 Iris 有新成員並請 Iris 記住，之後才會派工過去。
  5. 把 assistants-data.js 裡的 status 改成 active，卡片就會顯示「已上線」。要新增助理時，複製一筆資料修改即可。
