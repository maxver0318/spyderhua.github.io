Jenkins Pipeline vs GitHub Actions

兩個最常見的 CI/CD 工具，都能在程式推上去之後自動測試、打包、部署。差別在於：Jenkins 是自己架、自己管的伺服器；GitHub Actions 是 GitHub 內建的服務。這一頁整理它們的特色、能做的事、優缺點，最後用同一個專案各寫一份設定檔對照。

基本定位與特色

一句話：Jenkins 是「什麼都能接的自架自動化伺服器」，GitHub Actions 是「長在 GitHub 裡、由事件觸發的工作流程」。
