AI 協作開發流程

我如何和 AI 一起打造這個網站

這個網站的每一次改版，都是我和 AI 助理 Max 透過對話完成的。我決定方向、提供內容、審查成果；Max 負責實作、驗證，並整理成可以審查的 PR。

用對話提出需求 每次改版都有前後截圖 桌機／手機 × 淺色／深色

誰負責什麼

J

我（Joe）

    Max（AI 助理）

      我們用什麼工具溝通

      我不用坐在電腦前：提出需求、審查、上線，都在手機上完成。

      我（Joe）

      手機上的 Claude App

      我用手機版的 Claude 跟 Max 對話。想到要改什麼，打一段話就能交代，Max 有問題也會在對話裡直接問我。

      Max

      Mac mini 上的 Claude Desktop

      Max 是架在一台 Mac mini 上的 Claude Desktop。這台電腦專門給 Max 使用：讀程式碼、修改、用 Chrome 截圖、推送分支、開 PR，都在這台機器上完成。

      我（Joe）

      手機上的 GitHub App

      Max 開好 PR 後，我用 GitHub App 看 PR 的說明與前後截圖，確認沒問題就直接點 Merge 按鈕，網站自動更新。

      一次改版的流程

      從提出需求到網站上線，每一步由誰負責、做了什麼。

      我（Joe）
      Max

      Max 怎麼做

      流程裡比較關鍵的幾個做法。

      每個 PR 的固定格式

      我只要看 PR 說明，就能判斷這次改版能不能上線。

        改版紀錄

        最近 6 個用這個流程合併的 PR，點擊可以在 GitHub 看到完整的說明與截圖。

          我給 Max 的提示詞

          每次請 Max 做事時實際打的那段話，附上做出來的成果。想做類似的東西，可以直接複製來改。
